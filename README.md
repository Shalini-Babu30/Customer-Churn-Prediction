# Customer Churn Prediction
## Overview
This project predicts whether a customer is likely to churn using Machine Learning. It provides an interactive web application built with Streamlit where users can enter customer information and receive churn predictions instantly.
## Features
- Customer churn prediction
- Interactive Streamlit interface
- Data preprocessing
- Machine Learning model
- Business-friendly prediction output
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
## Dataset
Customer business dataset containing customer demographics and behavioral information.
